# عيون الغزال
- تشغيل محليًا: `python -m http.server` ثم http://localhost:8000
- النشر: GitHub > Settings > Pages > Branch main / root.
- رقم واتساب: `whatsapp` في data/site.json.
- تصميم جديد: أضف كائنًا في data/designs/<قسم>.json. حقل `preview` يقبل مسارًا داخليًا أو رابطًا خارجيًا كاملًا (https://...).
- قسم جديد: انسخ categories/<قسم>.html وغيّر data-theme وdata-json، وأضف ملف JSON وعنصرًا في data/categories.json.
